Project Overview

**Project Name:** Bubble Pixel Art Converter
**Inspiration:** A creative reel showcasing bubble-styled pixel visuals.

This is a web-based image transformation tool that converts standard images (PNG, JPG, JPEG) into vibrant, circular bubble-style pixel art. It is fully responsive and interactive, offering users control over **bubble size, image contrast, brightness, saturation**, and resolution quality.

**Key Features:**

  • Intuitive Drag & Drop Image Upload (up to 10MB).
  • Real-Time Adjustments via dynamic sliders for fine-tuning.
  • Aesthetic 3D-looking pixel bubbles with hover interactivity.
  • Optimized for Performance with visual progress tracking.

Technologies Used:
